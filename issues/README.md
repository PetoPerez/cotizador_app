# Bitácora de issues y soluciones — cotizaciones_app

Respaldo permanente de los problemas reportados y **cómo se resolvieron**, para no
perder el contexto ni repetir diagnósticos. Cada issue vive en su propio archivo.

## Convención

- Nombre de archivo: `AAAA-MM-DD-slug-corto.md` (fecha del reporte/solución).
- Un archivo por problema. Si un tema evoluciona en varios commits, se listan todos.
- Estados: **Resuelto** · **Abierto** · **En espera** (esperando info de terceros).

## Plantilla

```markdown
# <Título del issue>

- **Fecha:** AAAA-MM-DD
- **Estado:** Resuelto | Abierto | En espera
- **Commit(s):** <hash> …
- **Reportado por / contexto:** …

## Síntoma / reporte
## Diagnóstico (causa raíz)
## Solución
## Archivos tocados
## Verificación
## Prevención (que no reaparezca)
```
