## Cómo obtener un PDF de un manual

Los manuales están en formato Markdown. Para convertir cualquiera a PDF puedes:

- Abrirlo en un editor Markdown (VS Code, Typora) y exportar a PDF, o
- Pedir que se genere una versión web/PDF lista para compartir.

> Los manuales reflejan la versión más reciente del sistema (moneda en dólares
> por defecto con opción a pesos; equipos en Servicios de Lavandería solo de
> Supliese).
